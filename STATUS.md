# Project status (public)

This is a public research and product-shell repository, not evidence of a
production exchange, live QPU execution, or quantum advantage. For the dated
research posture, see [RESEARCH-STATUS.md](RESEARCH-STATUS.md) (as of
2026-09-20). This page describes what the repository contains; it does not
certify the current status of private projects or external services.

| Area | Evidence here | Limit |
| --- | --- | --- |
| Bottlenecks | `bottlenecks/` publishes 999 source-grounded notes, an index and embeddings | Notes are not peer review; keyword search is not semantic search |
| Erdős lanes | `research/quantum-erdos-sequences/` contains 999 Qiskit Aer simulator scripts | `LOCAL_SIM` only; finite examples do not solve open problems or establish speedup |
| Product | `index.html`, `app.js`, `styles.css` provide a UI shell | No live exchange or QPU service is established by this repository |
| Hardware | [Research status](RESEARCH-STATUS.md) records job submission locked as of 2026-09-20 | No `REAL_QPU` result is documented here |
| CI | [CI honesty](docs/ci-honesty.md) describes the checks present in this repository | No tracked GitHub Actions workflows or automated status gate |
