# Honesty index

This is a documentation index, not a results report. Claims in this repository
must match the evidence actually linked in the repository or in a reproducible
receipt.

| Claim area | Public-safe statement | Evidence required for a stronger claim |
| --- | --- | --- |
| Yield, return, or fidelity | No measured yield, return, or fidelity is reported here | A dated, reproducible receipt and method |
| Simulation | `LOCAL_SIM` identifies simulator work only | Linked run output and a stated classical baseline |
| Hardware | No `REAL_QPU` result or quantum advantage is claimed | Explicit unlock, hardware receipt, and reproducible comparison |
| DeepNet | The [DeepNet master](https://agenci-main.github.io/deepnet-chat/) is an external documentation link | Separately verified behavior; this repository does not define its runtime or schema |
| Exchange | The site is a product shell and public research surface | Evidence of a live backend and operational service |

The [QPU hold](HONESTY-QPU-HOLD.md) and [org-ops index](ORG-OPS.md) apply to
all documentation in this repository. Do not turn a proposal, estimate, or
simulator output into a measured result.
