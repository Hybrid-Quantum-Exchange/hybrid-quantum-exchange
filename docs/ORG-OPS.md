## Operating boundaries

- **Documentation-only / QPU Hold.** No QPU submission or unlock is authorized.
- **No privileged changes.** No Settings, billing/IAM, invites, or secrets work.
- **No DeepNet changes.** The [DeepNet master](https://agenci-main.github.io/deepnet-chat/)
  is an external documentation reference only; this repository does not define,
  verify, or connect to its runtime, schema, or API.
- **No FIRE work.**
- Do not present simulation as hardware evidence, or claim yield, fidelity,
  quantum advantage, live exchange operation, or financial returns without
  appropriate reproducible evidence.

These boundaries summarize the public repository documentation; they do not
describe or grant access to private systems. See the [status page](../STATUS.md)
and [honesty / QPU Hold](HONESTY-QPU-HOLD.md) for qualifications.
