# Organization operations note

This repository publishes documentation and research notes; it does not
establish live service operations, organization permissions, or a working CI
pipeline. See the [CI evidence index](CI-EVIDENCE-INDEX.md) for the documented
checks and the CI evidence that is still missing.

For this documentation-only change, do not access or change organization
settings, billing/IAM, invitations, secrets, QPU controls, DeepNet runtime or
schema, or FIRE. Keep the pull request in draft and do not merge it.

The [DeepNet master](https://agenci-main.github.io/deepnet-chat/) is an
external documentation reference, not an integration or operational control
plane for this repository.
