# ORG-OPS boundary (public)

**Snapshot: 2026-09-30.** This is a public documentation boundary, not an
operations console, approval, or execution record. The burn-wave work in this
repository is docs-only.

## Allowed in this repository

- Update README, progress, status, honesty, and evidence-index documentation.
- Link the [DeepNet master](https://agenci-main.github.io/deepnet-chat/) as an
  external documentation reference.
- Describe proposed CI checks and the evidence still needed to support them.
- Report only reproducible, source-grounded facts already present in the
  repository.

## Explicitly out of scope

This boundary does **not** authorize QPU or cloud execution, settings,
billing/IAM, invitations, secrets, DeepNet runtime or schema work, or FIRE.
`LOCAL_SIM` documentation is not a `REAL_QPU` result. No yield, fidelity,
speedup, return, or quantum-advantage number is asserted without a linked
receipt and reproducible baseline.

## Evidence rule

An index or documentation claim is not a CI receipt, execution approval, or
production-readiness claim. Proposed checks and missing evidence are tracked in
[CI evidence](CI-EVIDENCE.md); the public posture is summarized in
[STATUS.md](../STATUS.md) and [RESEARCH-STATUS.md](../RESEARCH-STATUS.md).
