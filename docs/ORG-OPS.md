# Org operations posture

**Snapshot: 2026-09-30.** This is a public documentation boundary, not an
organization-control-plane report or an authorization.

## Allowed in this pass

- Update public README, progress, status, honesty, and evidence-index documentation.
- Link the [DeepNet master](https://agenci-main.github.io/deepnet-chat/) as an external,
  text-only documentation reference.
- Record evidence gaps without filling them with estimates or invented measurements.

## Explicitly out of scope

**NO QPU, NO Settings, NO billing/IAM, NO invites, NO secrets, NO DeepNet runtime/schema,
NO FIRE.** No hardware or paid-cloud submission is authorized, and no `REAL_QPU` unlock
or receipt is claimed. `LOCAL_SIM` documentation must not be presented as hardware evidence.

## Honesty rules

- A link is not an integration, availability check, or execution receipt.
- A proposed CI gate is not a passing CI run.
- Do not report yield, fidelity, speedup, quantum advantage, uptime, or financial return
  unless a reproducible, dated receipt supports the specific claim.
- This repository remains a public research surface and product shell, not a live exchange
  or organization operations console.
