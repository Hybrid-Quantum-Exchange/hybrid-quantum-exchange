# DeepNet master operator map

**Snapshot: 2026-09-30.** This is a public documentation map, not an
operational control plane. The [DeepNet master](https://agenci-main.github.io/deepnet-chat/)
is the documented operator entry point; this repository does not configure,
call, or verify its runtime, schema, availability, or results.

## Allowed in this repository

- Update README, progress, status, honesty, organization-operations, and CI
  evidence documentation.
- Link to public research and label simulator work `LOCAL_SIM`.
- Record reproducible evidence links when they exist.

## Explicit hold

**NO QPU, NO Settings, NO billing/IAM, NO invites, NO secrets, NO DeepNet
runtime/schema, NO FIRE.** Do not submit hardware jobs, unlock submission, or
describe estimates as measured yields, fidelity, returns, speedup, or quantum
advantage. No `REAL_QPU` result is established here.

## Evidence rule

Every stronger claim needs a dated, reproducible receipt and an appropriate
classical baseline. The [CI evidence index](CI-EVIDENCE.md) lists documented
checks and the evidence still missing; an index entry is not a passing run.

See the [honesty / QPU hold](HONESTY-QPU-HOLD.md), [public status](../STATUS.md),
and [vault map](VAULT.md) for the surrounding boundaries.
