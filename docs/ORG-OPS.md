# Organization operations boundary

This is a public documentation index, not an operational control plane or authorization. Work in this scope is limited to repository documentation and truthful status/evidence links.

## Hard boundaries

- No QPU or paid-cloud submissions, unlocks, or claims of `REAL_QPU` results.
- No Settings, billing/IAM, invites, secrets, or FIRE work.
- No DeepNet runtime, schema, or integration changes. The [DeepNet master](https://agenci-main.github.io/deepnet-chat/) is a reference link only; availability and behavior are not verified here.
- No invented yield, fidelity, pass-rate, or other performance figures. Report only figures supported by linked, reproducible evidence, with their scope and limitations.

## Public documentation and evidence

- [README](../README.md), [public status](../STATUS.md), and [documentation progress](../PROGRESS.md) describe this repository's public scope.
- [Research status and CI evidence index](../RESEARCH-STATUS.md#ci-gates-and-receipts-index-not-run-results) distinguishes proposed gates from run receipts. It does not claim CI results where receipts are absent.
- [Honesty / QPU hold](HONESTY-QPU-HOLD.md) records the evidence bar and hardware hold.

This index does not grant organization or repository permissions, and it is not evidence that an external service, CI run, or hardware job is active.
