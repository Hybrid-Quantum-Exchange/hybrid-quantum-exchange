# Org-ops index

This public repository records documentation and evidence pointers only. It
does not authorize changes to organization settings, billing, IAM, invitations,
secrets, QPU access, DeepNet runtime or schema, or FIRE.

| Surface | Public posture |
| --- | --- |
| Repository docs and CI evidence | Allowed when claims remain linked and reproducible |
| QPU or paid cloud execution | Hold; no submission or unlock |
| Organization settings, billing, and IAM | Out of scope |
| Invitations and secret handling | Out of scope |
| DeepNet runtime or schema changes | Out of scope; [DeepNet master](https://agenci-main.github.io/deepnet-chat/) is link-only |
| FIRE | Out of scope |

See the [vault map](VAULT.md) for the public/private split and the
[honesty index](HONESTY-INDEX.md) for claim rules.
