# Public org/ops boundary

**Snapshot: 2026-09-30.** This page records the public operating boundary for
this repository. It is not an incident log, access list, or service-status
feed.

## Allowed in this repository

- Documentation, research notes, simulator documentation, and CI evidence
  indexes.
- Links to the [DeepNet master](https://agenci-main.github.io/deepnet-chat/) as
  an external documentation reference only.
- Honest labels such as `LOCAL_SIM` and explicit statements of missing
  evidence.

## Held or out of scope

**NO QPU, NO Settings, NO billing/IAM, NO invites, NO secrets, NO DeepNet
runtime/schema, NO FIRE.** No hardware or paid-cloud submission is authorized;
there is no `REAL_QPU` unlock in this documentation-only update.

The public repository does not grant access to private control-plane
operations. See the [vault map](VAULT.md) and [honesty ledger](HONESTY-QPU-HOLD.md).
