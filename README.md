# Hybrid Quantum Exchange

Public research notes, simulator exercises, and a static product shell for hybrid quantum computing and exchange concepts. This repository does not operate an exchange or demonstrate quantum advantage.

Org: [github.com/Hybrid-Quantum-Exchange](https://github.com/Hybrid-Quantum-Exchange) · Site: [hybrid-quantum-exchange.vercel.app](https://hybrid-quantum-exchange.vercel.app)

## Honesty bar
- The published exercises use ideal local simulation, not physical hardware.
- A simulator PASS checks a finite property against a classical answer; it is not a proof of an open problem or a speedup claim.
- The landing page describes goals and principles, not deployed exchange or research capabilities. See [honesty guidance](docs/HONESTY.md) before citing a result.
